7 Ways How We Use AI Is Changing

First we were prompt engineers, then context engineers, then harness engineers, then loop engineers. It's tempting to dismiss each as a buzzword replacing the last — but this week's announcements from Meta, Anthropic, Cursor, and SpaceX AI suggest something more fundamental: the basic patterns of how we interact with AI are shifting, and this time, some of the shifts are likely to stick.

The One Idea

The way we use AI is being rewritten — and these changes look like they'll stick.

Seven interaction patterns are converging at once: interfaces are radically simplifying (Muse, Claude's Cowork-Chat merger), work is consolidating into long-running monothreads that never reset, chatbots have quietly become agent fleet managers, voice is table stakes, we set goals and design loops instead of writing prompts, multi-model personal stacks have gone from early-adopter alpha to cost requirement, and agents are finally going from individual silos to shared team infrastructure. How we use AI has never been static — but these shifts are fundamental enough to be worth your attention.

GP’s Corner

Claude’s notes on what today means for general practice and the NHS — commentary, not from the podcast itself.

Monothreads are powerful, and a problem for the medical record

A single long-running thread that carries context across weeks is how many power users now work, and it is tempting for practice managers and clinical leads handling recurring work such as QOF, rotas or complaints. But anything patient-identifiable that builds up in a personal AI thread sits outside the clinical record, outside the practice's information governance, and possibly in a consumer account. Keep long-running threads for non-identifiable operational work, and make sure anything clinical ends up in the record rather than in a chat history.

Loops, not prompts, is a good way to think about practice automation

The shift from writing prompts to setting goals with measurable success criteria maps neatly onto how general practice already improves things: audit cycles and PDSA. If practices use agents for searches, recall lists or letter backlogs, define the goal and the check up front, for example all patients on this register with an overdue review invited, verified against a search. Then let the tool iterate. The discipline of saying what done looks like is also what makes the output auditable.

Shared agents will need practice-level governance, not personal accounts

The move from personal agents to shared team agents is where general practice actually fits: work is done by teams across reception, dispensary, nursing and GPs, not by individuals. When shared agents reach NHS workflow tools, the questions are organisational. Whose authority does the agent act on? What can it see? Who reviews its output? Where is that written down? Getting that agreed at practice or PCN level before the products arrive will matter more than which product wins.

NLW’s Takes

The buzzwords aren't silly — they're the journey

Prompt engineers, then context engineers, then harness engineers, then loop engineers. It looks like one silly buzzword giving way to the next, but it's actually all of us together figuring out the best way to use a completely new technology — one changing both how we do current work and what work is even possible.

NLW isn't sold on unification — but admits he's out of sync

On a personal level, the host still likes having more specific control over which mode he's in. But the average user reaction is overwhelming and in the other direction: nobody wants two or three chatbots, agents, and terminals — they want a single interface where they ask, the platform coordinates and delegates, and they receive.

The AI Daily Brief itself now runs on monothreads

Everything on the show's website is managed from a single Claude Code thread — updates just pick up where the last session left off. The social clip pipeline is another thread, and the pattern has spread beyond code: recurring tasks like writing ad copy in Claude projects now start at the end of the last similar task rather than from scratch.

The simplicity push could collide with cost discipline

As labs simplify the average experience, they'll obscure or eliminate fine-grained controls like which tasks get which model. They'll try to build automated routing underneath — but they won't always get it right, so this is one area where users should preserve personal agency.

There's alpha in building shared agents before the norms settle

The show's free multiplayer AI sprint doesn't pretend the space is figured out — it walks teams through inventorying current AI use, writing down shared context, finding overlaps in workstreams, and then actually building shared agents. Waiting for the industry to settle is understandable, but teams that dive in now can get out ahead of the product wave that's coming.
